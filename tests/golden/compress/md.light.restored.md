# Compressor Guide

This guide shows how the compressor works on a sample document.



## Configuration options

The configuration options control the compressor. Each configuration option has a default value.   
The configuration options are read at start-up. Change the configuration options with care.

***

## Usage examples

Run the compressor on a file. The compressor writes a compact file next to the input file.
Run the compressor on a folder with the batch option. The compressor writes a compact file for each input file.
Run the compressor with the decompress option to restore the input  file from the compact file.

## Troubleshooting

If the compressor fails, read the error message. The error message names the input file.
If the compressor writes an empty compact file, check the input  file encoding.
If the compressor is slow, check the size of the input file.

___

## Summary

The compressor makes a compact file. The compact file is smaller than the input file.
